# 快速开始

欢迎使用 **简儿 NEXT 5**！🎉

简儿 NEXT 5 是基于 JianerCore 框架的生产级 QQ 机器人，带来了全新的插件架构、长期记忆系统和 Agent 工具支持。

::: tip 版本说明
本文档基于 **简儿 NEXT 5**（`dev` 分支）编写。NEXT 5 相比 NEXT 3 进行了架构级升级：
- 框架从项目内置切换为 PyPI 包 `jianer-bot`
- AI 对话、记忆、TTS、Agent 工具迁移到 `plugins/JianerAI/` 目录插件
- 新增内容审核、回复后记忆审查、状态化网页浏览器和完整的舞萌 DX 支持
- 插件热重载采用候选加载、原子交换机制
:::

## 部署流程一览

整个过程分为五个步骤，按顺序完成即可：

| 步骤 | 内容 | 预计耗时 |
| --- | --- | --- |
| [第一步：环境准备](/next5/deployment#环境准备) | 安装 Python 3.11/3.12 和必要的系统依赖 | 5~10 分钟 |
| [第二步：获取代码](/next5/deployment#获取代码) | 克隆仓库并切换到 `dev` 分支 | 2 分钟 |
| [第三步：安装依赖](/next5/deployment#安装依赖) | 创建虚拟环境并安装 Python 依赖 | 5~10 分钟 |
| [第四步：配置机器人](/next5/deployment#配置机器人) | 设置协议实现端、管理员和 AI 模型 | 10~15 分钟 |
| [第五步：启动运行](/next5/deployment#启动运行) | 启动协议实现端和简儿主程序 | 1 分钟 |

完成以上五步后，你的简儿 NEXT 5 就可以在 QQ 群里正式服务了！

## 核心特性

### 🤖 JianerCore 框架

NEXT 5 使用 `jianer-bot` PyPI 包作为核心框架，提供：
- 统一的适配器接口（OneBot/Milky/飞书/Kritor）
- 规范化的插件加载与派发机制
- 完整的生命周期管理和优雅关闭

### 🧠 长期记忆系统

- 按人设（preset）和会话隔离的规范化 SQLite 数据库
- 个人记忆、群记忆、对话片段和证据摘要分表存储
- 后台异步记忆审查，不阻塞用户交互
- 支持记忆创建、更新、列表、删除和恢复

### 🛡️ 内容审核

- 可选的独立审核模型，在主模型前进行内容安全检查
- 支持医学教育、新闻讨论等正当语境识别
- 审核通过后，主模型请求保持原样，不插入额外提示

### 🌐 Agent 工具

内置丰富的 Agent 工具：
- **基础工具**：当前时间、安全算术、发言人资料、会话资料
- **记忆工具**：长期记忆读取、创建、修改
- **网页搜索**：基于 ddgs 的多引擎文本搜索
- **GitHub 仓库**：只读查看仓库、目录、代码、Issue、PR
- **状态化网页浏览器**：基于 Playwright Chromium 的网页查看与操作
- **通用制图**：HTML/CSS 渲染和固定天气卡片模板
- **和风天气**：可选的 11 个天气与气候 Tool，覆盖 23 个操作

### 🎮 舞萌 DX

完整移植 `nonebot-plugin-maimaidx` v3.0.13：
- B50/AP50、单曲成绩、曲目搜索、别名管理
- 水鱼查分器和落雪查分器支持
- OAuth 无回调绑定（私聊安全授权）
- 猜歌、定数表、完成表等完整功能
- 集成到 JianerAI Agent 工具
